# Simulated four-fitting holdout

These twelve cases were generated with PlumeNav 0.21.0. They are synthetic ground-robot measurements, kept separate from the external experiments. The case list is read by `pnpm survey:validate --holdout`. `source` is the simulated release location in metres, `fitting` is the zero-based reference fitting index or null, `wind` is a compass heading in degrees and `speed` is the wind speed in m/s. `replicate` selects the deterministic seed set. Public fitting positions, inlet timing and model coefficients are in the [mission protocol](../../../docs/fitting-survey.md) and its runner. The simulator and scorer use the release coordinates. The controller only receives public geometry and observations.

The CSV files record reference outputs from the previously run holdout at commit `8f26458beb855bbd3b7c0dadbe9dd1fe3e4d94bd`. `missions.csv` and `decisions.csv` give the outcome and reason for each case. `visits.csv` and `verification-visits.csv` record the settled evidence. `readings.csv.gz` is an ordinary gzip-compressed CSV of the timestamped inlet observations in ppm excess. Run `pnpm validate:data` to regenerate and compare these traces, or `pnpm survey:validate --holdout new-output-directory` to keep a new run. The two releases 0.15 m from a mapped fitting still attract a reinspection flag. They are retained as known failure cases for distinguishing nearby sources.
