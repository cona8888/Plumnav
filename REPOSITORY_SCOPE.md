# Repository scope

This repository started as a source-only snapshot of PlumeNav Lab for cona8888/Plumnav.

Included: the React/TypeScript application in src/, development and scientific scripts in scripts/, package/lock files, and build/test configuration.

The original import copied source files without running the application, scripts, tests or scientific computations. This upload does not establish scientific validation or change any recorded research result. README.md retains the project's existing research descriptions and their stated limitations.

The original private research datasets, campaign archives, manuscripts, third-party source trees, AWS configuration/control packages, local credentials and generated releases remain outside this repository. The versioned public field-data extracts and the simulated fitting holdout are now included under `validation/`. Each external dataset has attribution and reuse terms. Some scripts and README links require those local materials; their absence here is deliberate. No AWS action or paid job is part of this upload.

The existing research workspace and its Git metadata were not modified by preparing this snapshot. The snapshot manifest records SHA256 and byte length for every selected original source file.

Subsequent engineering tests and the calibrated fitting-survey use case are documented in [the survey report](docs/fitting-survey.md). Its small result table and reproducible commands apply to this implementation. The snapshot manifest describes the original imported files.

The [November engineering audit](docs/reviews/2026-11-03-pstack/README.md) is now
included with its original report, reproducible probes and complete evidence
archive. The [version 0.22 implementation response](docs/review-followup-2026-11-04.md)
records the subsequent checkpoint/start fixes, versioned grid solver, fresh
verification and unchanged scientific limits. These bounded checks do not
revalidate the excluded private campaign archives or establish physical robot
performance. The installed-system pilot is documented as a proposed experiment.
