# Repository scope

This is a source-only snapshot of PlumeNav Lab for cona8888/Plumnav.

Included: the React/TypeScript application in src/, development and scientific scripts in scripts/, package/lock files, and build/test configuration.

The source files were copied without running the application, scripts, tests or scientific computations. This upload does not establish scientific validation or change any recorded research result. README.md retains the project's existing research descriptions and their stated limitations.

Research datasets, raw evidence, result archives, manuscripts, third-party source trees, AWS configuration/control packages, local credentials, generated releases, and ongoing research/results preparation are retained locally and are not included. Some scripts and README links require those local materials; their absence here is deliberate. No AWS action or paid job is part of this upload.

The existing research workspace and its Git metadata were not modified by preparing this snapshot. The snapshot manifest records SHA256 and byte length for every selected original source file.
